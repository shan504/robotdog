# RobotCar 素材说明

网站当前使用 21 张车类素材：9 张玩具车、8 张配件与 4 张场景。原机器狗、四足平台及厂家产品图片已从当前公开输出移除。

车类与配件图片由 `design/toy-car-studio.html` 中的原创三维模型渲染，包含 Sprint、Omni、Rover、Drift、Maker、Vision、Circuit、Cargo 与 Transform。渲染使用 Three.js；它不是生产网站的运行依赖。模型源文件通过 import map 引用 `/three/`，重新渲染时需在设计工作区安装并提供 Three.js 0.180.0。

四张科技场景通过图像生成工具创作，主题分别为蓝色模型赛道、STEM 工作台、户外遥控竞速和智能小车未来实验。网页使用 WebP 优化版本。

这些是概念视觉，不是实物商品摄影或厂商规格证明。商品正式销售前应使用与实际型号相符的图片与信息。素材列表和哈希见 `image-sources.json`。
